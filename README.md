# LNG_NI · LNG 탱크 품질검사 교육 플랫폼

LNG 탱크 부품 사진을 보고 양품·불량을 판단하고, AI 검사 결과와 비교하며 배우는 Streamlit 웹앱입니다. 실습과 역량평가를 거쳐 실제 사진의 AI 판정을 검토하고, 검증된 검토 사례를 챗봇의 답변 근거로 활용합니다.

현재는 **외부 검사 API와 AgentStream 챗봇을 연결하는 교육·검토 보조 서비스**입니다. 챗봇은 사진을 직접 보지 않으며, 검사 결과와 검증 사례의 텍스트를 참고합니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 검사 실습 | 예제 사진의 양품·불량을 직접 판단하고 AI 결과·정답과 비교, 오답 복습 |
| 역량평가 | 검사 3종의 사진을 양품·불량으로 분류, 80% 이상 정답 시 합격 |
| 판정 검토 | 사진을 최대 30장 업로드하고 AI 제안을 승인·거절, 수정 판정과 검토 사유 기록 |
| 마이페이지 | 실습·평가 현황, 검토 기록·사진 조회, CSV 내려받기, 사진 삭제 |
| 시험 문제 신청 | 보관된 검토 사진을 시험 문제로 신청하고 관리자가 정답 확인·승인 |
| LNG_NI 챗봇 | 현재 검사 결과를 참고한 질문 응답, 관련 검증 사례와 근거 표시 |
| 관리자 기능 | 시험 문제 승인, 챗봇 참고 사례 검증, 기업 소속 관리 |

### 검사 모델

| 검사 | 모델 | 대상 |
|---|---|---|
| 표면 상태 분류 | ViT | 탱크 클리닝·폼스프레이 상태 |
| 볼트·케이블 탐지 | EfficientDet | 볼트 체결·케이블 설치 상태 |
| 결함 영역 분할 | MaskDINO | 용접·표면·보온재·케이블·바인딩·절단 상태 |

모델 점수는 정답률이나 검증된 합격 기준이 아닙니다. 탐지·분할 후보가 없다는 사실만으로 사진 전체를 양품으로 확정할 수 없습니다.

## 이용 흐름

1. **검사 실습**에서 사진을 직접 판단하고 AI 결과·정답과 비교합니다.
2. **역량평가**에 응시합니다. 로그인한 계정의 평가 결과는 저장됩니다.
3. 평가에 한 번 이상 합격한 계정과 관리자는 **판정 검토**를 이용할 수 있습니다.
4. 현장 사진을 업로드하고 AI 제안을 승인하거나 거절한 뒤, 판정 근거·검토 사유를 작성해 저장합니다. 검사 기준·문서 조항은 선택 입력입니다.
5. **마이페이지 → 내 검토 기록**에서 사진·기록을 확인하고 시험 문제 또는 챗봇 참고 사례로 별도 신청할 수 있습니다.

## 검증 사례를 참고하는 챗봇

검토 기록이 자동으로 모델 학습에 사용되는 구조는 아닙니다. 사용자가 활용에 동의하고 관리자가 검증한 기록을 질문 시 검색해 전달합니다.

### 사례 등록·검증

1. 마이페이지의 검토 기록에서 행을 선택합니다. 기존 기록에 사유가 없다면 **검토 사유·검사 기준 보완**에서 작성합니다.
2. 텍스트 활용 범위를 확인하고 동의한 뒤 **사례 검증 신청**을 누릅니다. 사진 보관·시험 문제 신청과는 별도 동의입니다.
3. 관리자가 마이페이지의 **챗봇 참고 사례 검증**에서 최종 판정, 확인한 검사 기준·문서 조항, 검증 의견·적용 조건을 작성해 승인하거나 반려합니다.
4. 관련 질문을 하면 서버가 검증된 사례를 검색해 챗봇에 전달합니다. 답변에는 `[검토 사례 K번호]`로 인용하도록 요청하고, 실제로 전달한 사례의 근거 목록도 별도로 표시합니다.

분야 담당자가 사례의 판정과 기준을 확인해야 합니다. 관리자 승인만으로 현장 판정의 정확성이 보장되는 것은 아닙니다.

### 검색 범위와 철회

- **기업 소속 관리**는 관리자만 변경할 수 있습니다. 서버는 로그인 계정의 소속을 기준으로 같은 회사에 공유된 검증 사례만 검색합니다. 소속이 없는 계정의 사례는 본인만 검색할 수 있습니다.
- 개인 사례는 회사에 가입해도 자동 공유되지 않습니다. 다른 회사로 소속을 옮겨도 기존 사례의 공유 범위는 이동하지 않습니다.
- 접근이 허용된 검증 사례 중 검사 종류에 맞는 최신 최대 1,000건에서 키워드로 검색하고, 관련 사례 최대 3건의 텍스트 요약을 전달합니다.
- **사례 활용 철회**를 누르면 이후 검색에서 제외됩니다. 사유를 수정한 사례도 다시 신청해 검증받아야 합니다.
- 사례 검색에는 사진 파일·파일명·작성자 이름을 포함하지 않습니다. 검토 사유에 직접 적은 민감정보는 작성자가 확인해야 합니다.
- 이미 외부 챗봇 서버에 전송된 대화는 활용 철회 기능으로 삭제되지 않습니다.

### 챗봇에 전달되는 검사 정보

- 검사 종류·사용 모델, 현재 화면의 사용자 예상·선택·수정 판정, 공개된 정답을 전달합니다. 실습 정답은 제출 후 공개된 경우에만 포함합니다.
- 분류 검사는 선택 클래스·모델 점수·클래스별 확률·이미지 크기를 전달합니다. 위치 좌표나 후보 번호는 제공하지 않습니다.
- 탐지·분할 검사는 이미지 크기·전체 및 표시 후보 수·후보 번호·클래스·점수·사각형 좌표를 전달합니다. 번호는 화면 필터를 적용한 오버레이 번호에 맞춥니다.
- 단일 사진 결과는 최대 15개, 여러 사진을 비교하는 실습은 사진당 최대 3개 후보를 전달하고 생략 수를 명시합니다. 선택한 분할 후보는 요약 범위를 넘더라도 포함합니다.
- 좌표는 방향 보정된 이미지의 왼쪽 위 `(0, 0)`을 기준으로 하며, `bbox=[x1,y1,x2,y2]`, 단위는 픽셀입니다.
- 판정 검토 화면에서는 본인의 누적 검토 건수와 최근 기록 최대 5건도 전달합니다. 해당 기록은 검증 여부 미확인 자료로 구분하며 공식 기준으로 인용하지 않도록 안내합니다.
- **사진과 픽셀 마스크는 챗봇에 보내지 않습니다.** 사진을 직접 보았다고 말하거나 색상·질감·균열 모양 같은 시각적 근거를 지어내지 않도록 답변 지침을 전달합니다.

## 실행

Python 3.12 환경을 기준으로 하며, 의존성 버전은 `requirements.txt`에 고정되어 있습니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

기본 접속 주소는 `http://localhost:8501`입니다. 프록시 하위 경로에서 실행하는 경우 다음과 같이 경로를 지정합니다.

```bash
python -m streamlit run app.py --server.baseUrlPath <프록시-하위-경로>
```

- `app.py`가 `st.App`으로 화면과 인증·챗봇 중계 API를 함께 실행합니다.
- 챗봇 API 키가 없어도 화면·실습·계정 기능은 실행할 수 있지만 챗봇 응답은 사용할 수 없습니다. 사진 검사는 외부 검사 API 연결이 필요합니다.
- `chat_api.py` 등 서버에서 가져온 모듈의 변경은 서버를 재시작해야 반영됩니다. `tools/serve_dev.sh`는 현재 개발 서버 경로에 맞춰 파일 변경을 감지하고 재시작하는 스크립트입니다.

### 챗봇 설정

환경변수 또는 `.streamlit/secrets.toml`에 설정합니다. `chat_api.py`의 설정 조회는 환경변수를 먼저 확인합니다.

```toml
AGENTSTREAM_API_KEY = "발급받은 API 키"
```

| 설정 | 용도 |
|---|---|
| `AGENTSTREAM_API_KEY` | 챗봇 응답에 필요한 서버 전용 키 |
| `AGENTSTREAM_BASE_URL` | 기본값 `https://api-gateway.jntp-ax.or.kr/agentstream` |
| `AGENTSTREAM_WORKSPACE_ID` | 연동할 워크스페이스 ID. 미지정 시 코드 기본값 사용 |
| `AGENTSTREAM_CHATBOT_ID` | 연동할 챗봇 ID. 미지정 시 코드 기본값 사용 |
| `T13_SESSION_SECRET` | 방문자 쿠키 서명 값. 미지정 시 프로세스마다 새로 생성 |

`.streamlit/secrets.toml`과 `.env`는 Git에서 제외됩니다. 앱은 `.env` 파일을 직접 읽지 않으므로 셸에서 환경변수를 설정하거나 `secrets.toml`을 사용합니다.

### 데이터 경로 설정

다음 값은 환경변수로 지정합니다. 데이터는 서버의 로컬 디스크에 저장되므로 유지할 저장 공간과 백업이 필요합니다.

| 환경변수 | 기본값·용도 |
|---|---|
| `T13_DB` | `data/team13.db` — 계정·세션·실습·평가·검토·기업 소속·사례 검증 정보 |
| `T13_PHOTOS` | DB 디렉터리 아래 `photos/` — 동의한 검토 사진 축소본 |
| `T13_POOL` | DB 디렉터리 아래 `exam_pool/` — 시험 신청 사진 사본 |
| `T13_CASES` | 미지정 시 `demo_cases/raw/` 아래의 `samples.csv`를 사용. 지정 시 단일 예제 세트 경로 |

### 관리자 계정

`admin`은 일반 회원가입으로 생성할 수 없습니다. 서버의 동일한 DB 설정을 사용하는 환경에서 최초 한 번 생성합니다. 비밀번호는 입력 프롬프트로 받습니다.

```bash
python -c 'from getpass import getpass; import accounts; accounts.create_admin(getpass("관리자 비밀번호: "))'
```

관리자로 로그인하면 마이페이지에서 시험 문제 승인, 챗봇 사례 검증, 기업 소속 관리를 이용할 수 있습니다.

## 데이터 처리와 보관

| 데이터 | 처리·보관 방식 |
|---|---|
| 검사 입력 사진 | 지정된 외부 검사 API로 전송. 일반 JPEG·PNG는 원본 데이터를 보내므로 메타데이터가 포함될 수 있음 |
| 일반 실습의 업로드 사진·검사 결과 | 세션에서 사용하며 사이트 파일로 영구 저장하지 않음 |
| 계정·검토·실습·평가 기록 | SQLite에 저장. 비밀번호는 scrypt 해시, 로그인 토큰은 해시로 보관 |
| 동의한 검토 사진 | 긴 변 최대 1600px JPEG로 축소하고 EXIF 등 메타데이터를 제거. 본인 조회용으로 보관 |
| 사진 보관 기간 | 검토일로부터 90일이 지난 사진을 기록 조회·저장 시 삭제. 텍스트 기록은 유지 |
| 사진 수동 삭제 | 마이페이지의 **내 사진 모두 삭제**로 본인의 검토 사진 삭제 |
| 시험 신청 사진 | 신청 시 별도 복사. 관리자가 승인하면 평가 문제로 사용. 90일 삭제와 **내 사진 모두 삭제** 대상에 포함되지 않음 |
| 챗봇 질문·검사 정보·참고 사례 | 우리 서버를 거쳐 AgentStream으로 전송. 외부 서버에 대화 기록이 남을 수 있음 |

외부 검사 서버의 보관 기간과 모델 학습 재사용 여부는 이 저장소의 코드만으로 확인할 수 없습니다. 회사에서 반출을 금지한 사진은 업로드하지 않아야 합니다. 자세한 안내는 서비스의 **개인정보 및 데이터 안내**에서 확인할 수 있습니다.

`data/`, 비밀키, 가상환경, 실행 로그와 잠금 파일은 Git에서 제외됩니다. 예제 사진·라벨은 AI Hub의 「부품 품질 검사 영상 데이터(LNG 탱크)」에서 가져온 표본으로, 원본 데이터의 이용 조건을 확인해야 합니다. `demo_cases/incoming/`은 원본 데이터 임시 작업 공간이며 앱의 예제 경로와 구분합니다.

## 챗봇 연동 구조

```text
브라우저: 질문 + 현재 검사 정보
  → 우리 서버: 로그인·소속 확인, 검증 사례 검색
  → AgentStream: 검사 정보와 참고 사례를 포함한 텍스트 질문
  → 우리 서버: NDJSON 응답 중계
  → 브라우저: 답변·참고 문서·검증 사례·차트 표시
```

- 시스템 프롬프트는 AgentStream이 적용합니다. 앱은 `<inspection_context>` 텍스트와 답변 지침을 `message`에 포함합니다. API 키는 서버에서만 사용합니다.
- 대화는 방문자·로그인 계정·기업 소속·사례 상태 변경을 반영한 범위로 분리합니다. 서버 재시작 시 메모리의 대화 매핑은 초기화됩니다.
- 한글·JSON 조각과 중복 이벤트를 처리하며, 실패·중지·시간 초과 시 받은 답변과 상태를 표시합니다.
- 참고 문서와 검증 사례 출처를 표시하고, 차트 데이터는 Plotly로 그립니다. 모델이 생성한 HTML·JavaScript는 실행하지 않습니다.
- 앱의 중계 로그는 상태·단계·소요 시간 등을 기록하며 API 키와 대화 원문을 기록하지 않습니다.
- 상태 확인 경로: `GET {baseUrlPath}/api/t13/chat/health`. 상태 확인 성공과 실제 답변 완료 여부는 별도로 확인해야 합니다.
